# Apresentação — Dev: dicas de carreira pra Juninho

Slide deck HTML (paleta Norte4j) para meetups e bate-papos.

## Abrir localmente

```bash
cd apresentacao
python3 -m http.server 8080
```

Acesse: `http://localhost:8080/dev-juninho-30-slides.html`
